## F-013：已正規化比率被再次除以 100（已修正）

網站 model_one 把中央 `105`／`105%`／`1.05` 都正規化為 `1.05`，但引擎 _rate 又把大於 1 的值除以 100，實際 KO 門檻變成 1.05%。反例：10/15 收盤為期初的 100%，10/16 才到 105%；舊引擎在 10/15 提前 KO，3 個交易日的票息僅計 2/3。

修正：共用引擎的數值參數統一視為比率，`1.05` 就是 105%；只有明確帶 `%` 的字串才除以 100。中央模型仍負責原始 Sheets 顯示單位轉換。所有正式呼叫位置已搜尋，只有中央模型呼叫 calculate_v2；沒有建立另一套引擎。

這也修正 Strike、KI、年化率超過 1 時的相同轉換錯誤。直接呼叫引擎者須傳 `1.05` 或 `105%`，不能把無單位的 `105` 當百分數。正常中央 API 數值與百分比字串介面維持原行為。
