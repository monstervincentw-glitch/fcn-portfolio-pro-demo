## 覆蓋後驗收

- 登入前柴犬財神帽圖完整顯示；在手機上圖片在上方、PIN 表單在下方。
- 輸入 PIN 後，FCN 商品 > 日常監控顯示執行中商品（例如 SAE9；視資料內容而定）。
- 「全部商品」、「待建檔」、「歷史歸檔」切換正確。
- FCN 歷史試打及顧問工作台沒有回歸問題。
